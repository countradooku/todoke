# Formal models

Reserved for models of the protocol and transfer invariants defined in [spec/PROTOCOL.md](../spec/PROTOCOL.md). No model or proof exists yet.

Once transitions are specified, model session authentication, signed AcceH consent gating, PSK ratchet concurrency and crash recovery, and transfer completion. State the assumptions and properties checked, preserve counterexamples, and document a reproducible model-checking command. Choose a tool when the first model is designed; this scaffold does not imply verification coverage.
